## D. Release/safety gates that remain OPEN

- **C3:** per-slot hashing and two temporally consistent reads, independent reroll on each slot, double reroll, animation/transient unknown retry and backoff. No misassignment of unchanged slots.
- **C4:** verified offer present/gone, tooltip/dialogue/occlusion, no phantom selection, no false disappearance from death/focus. Confirmation remains user-driven.
- **Native M5:** minimum 10 offers / 30 cards with all three positions tested, each rerolled at least once and one twice; all visible names correct or clearly unknown. An isolated screenshot is not acceptance.
- **Native M4/UI:** actual Windows League windowed/borderless, 1080p and observed ~1440p clients, DPI, negative displays, focus/Alt+Tab, Qt opacity and click-through, single-instance Settings.
- **Data quality:** G1/G2 current patch Mayhem catalog, provenance, enemy items, feasible purchase and full six-slot inventory; do not force scores when model data absent.
- **Security/policy:** G4 localhost API Host/Origin/auth, Riot policy/licensing, use only visible/read-only data and no automatic purchases/choices; do not enable experimental empirical evidence by default.
- **Product UX:** user-approved event-driven quiet companion: champion selection, relevant three-card offer, shop-only build, optional scoreboard, otherwise hidden/minimal. No permanent debug sidebar. Installer and UI redesign follow functional acceptance.
