DESKTOP COMPANION

General

Configure your companion before a match. The desktop window is interactive; the in-game overlay remains separate.

Getting started

Choose a preferred build style under Build Preferences. Check the OCR dependency under OCR, and use Feedback to report incorrect or missing advice.

Window behavior

Closing Settings hides it to the notification area when the system tray is available. Open Settings again from the ARAM Oracle tray menu. Use Quit ARAM Oracle to stop the desktop companion.

Appearance and position

Position and appearance apply after saving to the running Qt overlay.

Positive offsets move inward from the selected corner; negative offsets move outward but are clamped within the display. Positions use Windows DPI-aware logical pixels.

ABOUT THIS COMPANION

About

ARAM Oracle is an experimental companion for League of Legends ARAM Mayhem.

How it works

Build and augment information is advisory. No in-game purchases, champion picks or augment choices are automated.
